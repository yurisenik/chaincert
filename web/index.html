Проверка цепочки TLS

Проверьте сертификаты сервера или соберите полную цепочку из PEM. {{.ProbeLabel}}

Источник сертификата

Домен без https:// и пути. Другой порт: example.com:8443.

Вставьте один сертификат или цепочку в PEM. Приватный ключ не нужен.

Только публичные сертификаты. Ключи не отправляются.

Как устроена цепочка

  1. ●
    Сертификат сайтаПодтверждает имя вашего сервера
  2. ●
    Промежуточный центрСвязывает сайт с корнем доверия
  3. ●
    Корневой центрОбычно уже есть у клиента

Серверу нужна полная цепочка: сертификат сайта, затем промежуточные сертификаты в порядке их выдачи.

        Установка на сервер
        
        
        
          
        
            В fullchain.pem сначала идёт сертификат сайта,
            затем промежуточные. Приватный ключ хранится отдельно на вашем
            сервере.
          
        
          
        
            В Nginx укажите fullchain в ssl_certificate, а ключ — в
            ssl_certificate_key. В Apache 2.4.8+ используйте
            SSLCertificateFile для fullchain.
          
        
          
        
            Проверьте конфигурацию, перезагрузите сервис и повторите проверку
            адреса. Результат сборки цепочки сам по себе не гарантирует доверие
            всех клиентов.
